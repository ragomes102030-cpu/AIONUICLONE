# Estrutura de memorial descritivo

## Contents
- Estrutura mínima

- Erros comuns

## Estrutura mínima

```
1. OBJETO
2. PREMISSAS
3. NORMAS APLICÁVEIS
4. DESCRIÇÃO DOS SERVIÇOS
5. CRITÉRIO DE MEDIÇÃO
6. CRITÉRIO DE RECEBIMENTO
7. REFERÊNCIA DE PREÇO (se orçamento)
```

## O que cada seção contém

### 1. OBJETO
Uma frase. O que está sendo descrito, para qual obra.
> "Execução de alvenaria de vedação em blocos cerâmicos, casa unifamiliar."

### 2. PREMISSAS
Os números que condicionam o resto. Sem isso, o memorial não é verificável.
> Área: 260 m² | Pé-direito: 2,80 m | Espessura: 14 cm | Ambiente: urbano

### 3. NORMAS APLICÁVEIS
**Número + ano**, e o item quando aplicável.
> NBR 15270-1:2017 (bloco cerâmico)
> NBR 15575-4:2021 (vedações verticais)

### 4. DESCRIÇÃO DOS SERVIÇOS
Material, dimensão, resistência, método executivo, tolerâncias.
> Bloco cerâmico furado 14×19×39 cm, furos horizontais, resistência ≥ 1,5 MPa.
> Argamassa 1:2:9, juntas 10 mm ± 2 mm, contrapassadas.

### 5. CRITÉRIO DE MEDIÇÃO
**Como se mede.** É o que evita disputa na medição.
> "Por m² de parede acabada, descontando vãos > 2,0 m²."

**Sem esta seção, a medição é contestável.**

### 6. CRITÉRIO DE RECEBIMENTO
**O que caracteriza aceito.** Deve ser verificável objetivamente.
> - Prumo: desvio ≤ 5 mm/m
> - Planeza: desvio ≤ 5 mm em 2 m
> - Resistência: laudo do bloco ≥ 1,5 MPa

**Sem esta seção, não há como recusar serviço ruim.**

### 7. REFERÊNCIA DE PREÇO
Base, UF, mês, desoneração.
> SINAPI SP, 09/2026, desonerado — R$ 47,24/m²

## Critérios obrigatórios

| Critério | Por que é obrigatório |
|---|---|
| **Medição** | sem ele, a medição vira negociação |
| **Recebimento** | sem ele, não há base para recusar |
| **Normas com ano** | NBR sem ano não é conferível |
| **Data-base do preço** | preço sem data envelhece |
| **Desoneração** | muda o custo significativamente |

## Erros comuns

| Erro | Consequência |
|---|---|
| Sem critério de medição | disputa na medição |
| Sem critério de recebimento | não se recusa serviço ruim |
| "Conforme NBR" sem número | não é conferível |
| Memorial copiado de outra obra | gera aditivo |
| Preço sem data-base | envelhece e não se defende |
| Desoneração não declarada | diferença grande em mão de obra |
| Texto genérico | não descreve o serviço real |

## Checklist

- [ ] As 7 seções presentes
- [ ] Premissas com números
- [ ] Normas com número **e** ano
- [ ] Descrição com material, dimensão, resistência, método
- [ ] Critério de medição explícito
- [ ] Critério de recebimento verificável
- [ ] Preço com base, UF, mês, desoneração
- [ ] Texto específico para esta obra (não copiado)
